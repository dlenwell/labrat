See your lab the way it is cabled

Every screenshot is from an invented demo lab.

Read-only by design

It only reads

The collector never changes a controller's settings, logs in to a device to change it, or sends a UPS a command.

It stays in bounds

It contacts the controllers you connect and, beyond them, only the networks you allow in Settings.

Secrets stay put

Credentials live in a local config file, never in the database.

You decide where things go

What a scan finds stays separate from your inventory until you place it or link it.

Quick start

With Docker and Compose:

git clone {{ repo_url }} labrat && cd labrat
mkdir -p deploy/data deploy/config
export LABRAT_UID=$(id -u) LABRAT_GID=$(id -g)
LABRAT_ALLOWED_HOSTS=labrat.example.lan \
  docker compose -f deploy/compose.yaml up -d --build
docker compose -f deploy/compose.yaml logs web | grep "setup code"

Open http://<host>:8000, choose First-time setup, enter the code from the log, then connect your controllers under Settings → Integrations. The setup guide covers running from a checkout, HTTPS, and upgrades.
