Browser session API

Protected routes use the same signed browser session as the HTML app. Writes require an administrator, JSON body, and X-CSRF-Token. The health route is public. This page lists the current code contract rather than private inventory data.

Machine API

Routes marked API token are for programs, not browsers. An administrator creates a token in Settings → API tokens with a name, an expiry, and the scopes it may use; the program sends it as Authorization: Bearer <token>, with no session cookie or CSRF token. A token reaches only the routes its scopes allow, never the browser pages or the session API. The token is shown once when created; LabRat keeps only its fingerprint. Revoke one you no longer need.
