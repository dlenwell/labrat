01 / EXPORT

Take everything with you

Download one file with this whole install: inventory, discoveries, accounts, history, and every integration.

The file contains your integration credentials (API keys, tokens, passwords) and every account's password hash. Store it like a password, and delete copies you no longer need.

02 / IMPORT

Replace this install

Import an export to make this LabRat the one you exported. Use it on a new install.

Everything here is replaced: inventory, discoveries, accounts, history, and integrations. Nothing here is kept or merged. Afterwards you sign in with an account from the exported install.

LabRat export · ZIP · up to 256 MB

What stays with this install

Three settings describe where LabRat runs rather than your lab, so an import leaves them as they are: the host names it answers to ([server]), where its database lives ([database]), and its session key and cookie settings ([auth]). The export leaves them out.

An export from an older LabRat is updated as it is imported. One from a newer LabRat is refused; update this install first.
